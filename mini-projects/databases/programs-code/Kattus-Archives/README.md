# Kattus Archives

A personal library to have accountability of the books I read.
## 🎓️ Appendix

This is my first project (even if it is not so large or complex) and for it I also used for the first time a layered structure (for study purposes).

This project was developed using Java + Oracle SQL + Docker
## ⚙️ Tech Stack

**Client:** Java

**Server:** Oracle SQL Express

**Container:** Docker
## 📋️ Lessons Learned

**Docker:**
- Build and use Docker compose

**General:**
- Create a project using a layered architecture
- Write a "good" readme

**Java:**
- Create custom exceptions
- Create a Database connection with a Java proyect
- Use SQL queries as a CRUD from Java
- Use interfaces (DAO) as a template for the SQL queries methods

**Git & Github:**
- Manage the project with git (commit, branch, merge, etc)
- Guide myself through Github
